# GAIT AI 1.0

شناسه برنامه: `ir.gaitai.analyzer`

## امکانات نسخه اولیه
- نمایش زنده دوربین پشت
- تشخیص یک بدن با MediaPipe Pose Landmarker
- استخراج ۳۳ نقطه کلیدی بدن
- نمایش اسکلت روی تصویر
- هشدار در صورت دیده نشدن نقاط اصلی بدن

## ساخت APK
این مخزن با GitHub Actions ساخته می‌شود. پس از ثبت فایل‌ها روی شاخه main، گردش‌کار Build GAIT AI APK اجرا می‌شود. فایل APK از بخش Artifacts همان اجرای موفق قابل دریافت است.

## محدودیت‌ها
این نسخه هنوز ویدئوی ضبط‌شده را وارد نمی‌کند و محاسبه چرخه گام، سرعت کالیبره‌شده، طول قدم یا گزارش پزشکی ندارد. خروجی فعلی فقط تخمین دوبعدی نقاط بدن است و برای تشخیص بیماری یا ویژگی‌های شخصیتی طراحی نشده است.

مدل MediaPipe در زمان build از مخزن رسمی Google دریافت می‌شود.
