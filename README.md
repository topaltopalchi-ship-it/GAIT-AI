# GAIT AI

Android prototype for live human-pose visualization.

- Package: `ir.gaitai.analyzer`
- Initial version: live camera, MediaPipe Pose Landmarker, 33 body landmarks, skeleton overlay.
- Build workflow: [Build GAIT AI APK](https://github.com/topaltopalchi-ship-it/GAIT-AI/actions/workflows/android.yml)

After a successful run, download the `GAIT-AI-debug-apk` artifact from the workflow run.

See [README_FA.md](README_FA.md) for Persian documentation and current limitations.

**Important:** this prototype visualizes body landmarks only. It does not yet calculate validated gait metrics or diagnose medical conditions.
